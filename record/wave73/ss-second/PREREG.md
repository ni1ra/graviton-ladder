## 1. The statements under test (first-hand, page images)

Paper: Satishchandran and Sorce, "Uniqueness of null-local modular flow", arXiv:2607.20678v1.

- Scalar (pp. 8-11): Phi = u^{(D-2)/2} phi, F = u^{(D-2)/2} Ef, phi[f] = -2 int_{C-} du dOmega F d_u Phi (2.15);
  omega_vac(phi[f1] phi[f2]) = -(1/pi) lim int du1 du2 dOmega F1 F2 / (u1-u2-i eps)^2 (3.4), i.e.
  <d_u Phi d_u Phi> = -(1/4pi) delta_{S^{D-2}} / (u12 - i eps)^2. The flow acts on d_u Phi as the
  diffeomorphism generated by 2 pi u(1-u) d_u (p. 11).
- p. 24: "massless gauge fields like the free graviton or the free Maxwell field (which is
  non-conformal in D != 4)". p. 26: "except in conformally invariant settings (like the Maxwell field
  in D = 4), the state 'omega_0' with null-local modular flow will not be the vacuum state."
- B.1 Maxwell (pp. 28-30): observables A[f], f divergence free, compact support (B.3); gauge A_v = 0,
  A_u = 0 on C-; calA_A = u^{(D-4)/2} A_A (B.10); A[f] = -2 int F^A d_u calA_A (B.12);
  omega_0^EM = -(1/pi) lim int F1^A F2^B q_AB / (u12 - i eps)^2 (B.13).
- B.2 gravitons (pp. 30-32): observables gamma[f] = int gamma_ab f^ab, f symmetric and divergence free
  (B.16); A_GR = polynomials in gamma[f]; symplectic form with 1/(16 pi G) (B.18); the region D is
  ASSUMED invariantly defined (p. 31); Gaussian null gauge (B.20), frame (e)_A "unit normalized with
  respect to the round metric q_AB on the unit sphere"; trace argued to vanish using tip smoothness
  and "the fact that q^AB gamma_AB vanishes at the edge of C-"; free data s_AB = trace-free part (B.22);
  Omega_GR = (1/32 pi G) int du dOmega u^{D-6} q q (s1 d_u s2 - s2 d_u s1) (B.23);
  S_AB = u^{(D-6)/2} s_AB (B.24); gamma[f] = -(1/16 pi G) int du dOmega F^AB d_u S_AB (B.25),
  F_ab = u^{(D-6)/2} (Ef)_ab|C- "in Gaussian null gauge";
  (B.26): omega_0^GR(gamma[f1] gamma[f2]) = +(1/(32 pi^2 G)) int du1 dOmega1 du2 dOmega2
  F1_AB F2^AB delta_{S^{D-2}} / (u1 - u2 - i0+)^2  (printed with a PLUS sign; B.13 and 3.4 carry minus).
  Footnote 12: s_AB = O(u^2) near the tip.
- p. 32 verbatim: "It is straightforward to show that omega_0^GR defines a state on A^GR(D) which has
  geometric modular flow on C-. Since the linearized gravitational field is not conformally invariant,
  omega_0^GR is not the restriction of the vacuum state to D." (calligraphic D = the diamond; no
  dimension restriction stated.)

Claim of the first lane (as given to me): in D = 4, omega_0^GR IS the Minkowski vacuum restricted to
the gauge-invariant diamond algebra, normalisation included; and the vacuum modular flow is conformal
on the curvature, which on S is u(1-u) d_u plus a non-local term.

## 2. My routes (none uses a de Donder propagator, harmonic projection or point sampling of it)

Route A (helicity / TT mode sum, analytic). Quantise the TT graviton with standard creation
operators: action (1/16 pi G) sqrt(g) R, g = eta + gamma gives (1/64 pi G)(-d gamma_ij d gamma_ij) on TT
modes, so <gamma_ij gamma_kl>_TT = 32 pi G Pi_ijkl(k) x (scalar mode sum). The gauge-invariant null datum
on the cone is Psi(l,m) = R_abcd l^a m^b l^c m^d (l = generator tangent, m complex null transverse).
For a plane wave Psi = (1/2) e(v,v), v = (l.k) m - (m.k) l. Hence
  <Psi(x1;l1,m1) Psi(x2;l2,m2')> = 8 pi G T^ab T^cd d_a d_b d_c d_d W_D(x1-x2),
  T^ab k_a k_b = v1.v2, W_D = scalar Wightman function with i eps,
exactly (regulated, eps > 0). I evaluate this in closed form on the cone (x_i = u_i l_i), take the
eps -> 0 limit as a distribution on the sphere and in u, and compare with what (B.26) implies for
Psi through the Sachs relation Psi = -(1/2) u^-2 d_u (u^2 d_u (s/u^2)) (to be verified symbolically).
Route A' (commutator / Pauli-Jordan function, analytic): the antisymmetric part fixes the smearing
function K of a diamond observable against j = d_u^2 S; from it the moment (memory) conditions that
decide whether (B.25)-(B.26) are well defined on gauge-invariant observables, and which flow preserves
that algebra.
Route B (symmetry, light): the off-coincidence vanishing in D = 4 is the helicity statement
o1^A o1^B o1^C o1^D obar2^{A'}.. d_{AA'}..d_{DD'} (1/x^2) = 0, i.e. the two-point function of the
(2,0) field with Delta = 3; cited theorem (Mack 1977; Angelopoulos-Flato-Fronsdal-Sternheimer 1981) is
quoted from memory unless read this session; the computation does not rest on it.

VERDICT (fixed): D = 4 CONFIRMED on the algebra they define (gamma[f], f divergence free and supported in the diamond):
omega_0^GR with the corrected sign equals the Minkowski vacuum there, coefficient included (the coefficient is forced
by the commutator anyway). D = 5, 6: omega_0^GR is not the vacuum, as the paper says.
Caveat fixed with the verdict: the weight-1 flow F -> F o psi^-1 (the paper's scalar-type "geometric flow" on d_u S)
does not preserve int F du = 0, so it is not an automorphism of the gauge-invariant algebra; the vacuum modular flow
there is the weight-2 Moebius flow on j = d_u^2 S (conformal flow on the curvature), which on the potential reads
delta S = 2 pi [u(1-u) d_u S + 2 int_0^u S du'] up to a + b u. On the larger algebra of all int F d_u S (not gauge
invariant: tip-anchored shear) omega_0^GR has the weight-1 flow and is not a restriction of the vacuum (those
observables have divergent vacuum variance, 1/eps^2 at the tip). That larger reading is the only one I found under
which the p. 32 sentence could be defended at D = 4, and it is not the algebra the paper defines.
Not proved here: that curvature smearings exhaust gamma[f] (compact-support Poincare lemma for the Calabi complex,
standard, not rederived); the moment lemma is exact on samples, not a symbolic all-cases proof.
