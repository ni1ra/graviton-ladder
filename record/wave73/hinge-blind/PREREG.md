# HINGE-BLIND pre-registration

Lane: HINGE-BLIND, 2026-11-15. Written and pushed before any measurement on the ball
vacuum. The lane has not opened, listed or searched the sealed folder and does not know the
predicted constant. No code had been run when this file was committed.

## Quantity

Free massless scalar in 3+1 flat dimensions, angular sector l, radial field phi_l = r x (radial part
of the 3-d field), sector Hamiltonian

    H_l = 1/2 Int dr [ pi^2 + (d_r phi)^2 + l(l+1) phi^2 / r^2 ].

Unit ball B (R = 1). rho_l = reduced Minkowski vacuum on the ball, rho_l ∝ exp(-K_l).
Z_l = (g/2) Int_0^1 phi_l^2 dr. rho'_l ∝ exp(-K_l - 2 pi Z_l). Measured:

    A_l = tr( rho_l^{1/2} rho'_l^{1/2} ),     Q_l = l(l+1) (1 - A_l) / g^2 .

Cases g = +1, g = -1, their mean, and g = ±0.25.

## Lattice conventions

Sites r_j = j a, j = 1..N_tot, Dirichlet at j = 0 and j = N_tot + 1. Lattice variables phi_j = phi(r_j),
pi_j = a pi(r_j), [phi_j, pi_k] = i delta_jk, so H = (1/2a) (pi^T pi + phi^T K phi) with a
dimensionless tridiagonal K. Vacuum correlators X = <phi phi> = (1/2) K^{-1/2}, P = <pi pi> =
(1/2) K^{1/2}. Region A = sites 1..n. In these variables Int_B phi^2 dr = a Sum_j w_j phi_j^2.

- Primary discretisation ("D2-mid"): K_jj = 2 + l(l+1)/j^2, K_{j,j+1} = -1 (direct second
  difference of the radial field). Entangling surface midway between sites n and n+1:
  a = 1/(n + 1/2), weights w_j = 1 for j = 1..n.
- Secondary discretisation ("Sred-mid"): Srednicki's form,
  K phi-form = Sum_j (j+1/2)^2 (phi_j/j - phi_{j+1}/(j+1))^2 + l(l+1) phi_j^2/j^2, same boundary.
- Boundary-site variant ("D2-site"): a = 1/n, surface on site n, w_n = 1/2 (trapezoid), A = 1..n.
- N_tot = 4n by default; N_tot = 2n, 8n (16n at small n) for the outside-size study.
- n in {24, 32, 48, 64, 96, 128, 192}; l in {2, 4, 8, 16, 32} required, plus 3, 6, 12, 24 and
  larger l if cheap.

## Method (exact Gaussian, no perturbation theory)

1. X_A, P_A: eigen-decomposition of tridiagonal K in arbitrary precision (eigenvalues refined by
   Newton on the characteristic recurrence, eigenvectors by the three-term recurrence), checked
   by orthonormality and by K = V L V^T residuals.
2. K_l from the covariances alone: Cholesky X_A = L L^T, S = L^T P_A L, S = U nu^2 U^T,
   eps_k = log((nu_k + 1/2)/(nu_k - 1/2)); K_l = 1/2 (pi^T N pi + phi^T M phi) with
   N = L U (eps/nu) U^T L^T, M = L^{-T} U (eps nu) U^T L^{-1}.
3. Perturbed generator: M' = M + 2 pi g a diag(w), N' = N. Its Williamson form from Cholesky of N
   and the symmetric eigenproblem of L_N^T M' L_N (eigenvalues eps'^2). If M' is not positive
   definite the perturbed state does not exist on that lattice; that is reported as such.
4. Affinity, formula I: tau = rho^{1/2}/tr rho^{1/2} is Gaussian with symplectic eigenvalues
   (1/2) coth(eps/4) in the same normal modes;
   A = tr rho^{1/2} · tr rho'^{1/2} / sqrt( det(Xt + Xt') det(Pt + Pt') ),
   tr rho^{1/2} = Prod_k sqrt(2 sinh(eps_k/2)) / (2 sinh(eps_k/4)).
   Formula II (cross-check): tr(e^{-K/2} e^{-K'/2}) = [(-1)^n det(1 - T T')]^{-1/2} with the
   symplectic matrices T = S H(eps/2) S^{-1} generated by the two quadratic forms.
5. Arithmetic: arb (python-flint) / mpmath at several hundred to several thousand digits, chosen so
   that the smallest nu_k - 1/2 is resolved with margin; every reported number is recomputed at a
   higher precision and must agree to the digits quoted.

## Validation cases (known answers, before trusting any ball number)

- Thermal chain: X, P of e^{-beta H} for a small chain give back M = beta K/a-form, N = beta.
- Two-mode squeezed vacuum: reduced mode has nu = (1/2) cosh 2r, K = eps (x^2 + p^2)/2.
- A = 1 at g = 0; A symmetric under exchange of the two states.
- One and two modes against brute-force truncated Fock-space matrices (expm, traces) in double
  precision: both the affinity formula and "exp(-K) reproduces X, P".
- Formula I against formula II on the ball lattice itself.
- Lattice sanity: sector entanglement entropy against Srednicki's large-l expansion.

## Extrapolation rules

In n at fixed l. Data Q_l(n), x = a. Effective exponent from three doublings,
p = log2[(Q(48) - Q(96)) / (Q(96) - Q(192))].
- |p - 1| < 0.3: central value from Q = q0 + q1 x + q2 x^2 on the four largest n.
- |p - 2| < 0.5: central value from Q = q0 + q2 x^2 + q4 x^4 on the four largest n.
- otherwise, p > 0.4: three-point exact fit Q = q0 + c x^p on n = 48, 96, 192, p reported.
- p < 0.4 (differences not shrinking): no continuum limit at fixed l is claimed; dQ/d ln n is
  reported instead.
Bracket in n = largest spread between the central value, the neighbouring rule, and the same rule
with the largest n dropped.

In l. With Q_l = continuum values, doubling ratios rho_l = (Q_4l - Q_2l)/(Q_2l - Q_l) for
l = 2, 4, 8.
- "tends to a finite nonzero constant": the last two ratios satisfy |rho| <= 0.6, the extrapolated
  constant's bracket excludes zero and its half-width is below 20 percent of the constant.
  Central value from Q_l = Q_inf + b/L + c/L^2, L = l(l+1), on l >= 4; alternates Q_inf + b/l + c/l^2
  and Q_inf + (b + b' ln l)/L; bracket = spread of the three plus the propagated n-bracket.
- "grows logarithmically": last two ratios within [0.8, 1.25]. "grows as a power": ratios > 1.25.
- "tends to zero": Q_2l/Q_l < 0.6 over the last two doublings.
- anything else: undetermined, said so.

Consequence for the sum: if Q_inf = c is finite and nonzero, 1 - A_l -> c g^2 / (l(l+1)) and
Sum_{l<=Lmax} (2l+1)(1 - A_l) = 2 c g^2 ln Lmax + const, a logarithmic divergence with slope
2 c g^2 per e-fold of the l cutoff (bracket = twice the bracket of c). If Q_l falls as a positive
power of l the sum converges; if Q_l grows, the divergence is stronger than logarithmic.

Quadraticity in g: reported as the ratio Q(mean of ±0.25)/Q(mean of ±1) and the odd part
[Q(-g) - Q(+g)]/2 at both |g|. "Quadratic" is claimed only for the g -> 0 limit; the size of the
departure at |g| = 1 is reported, not argued away.

## Controls with planted errors

Wrong boundary weight in Int phi^2 (w_n = 0 and w_n = 2); float64 pipeline in place of high
precision; wrong sign of the perturbation (g -> -g, i.e. the g = +1 / g = -1 split itself);
additionally Z with the factor 1/2 dropped.

## Prior

Weakly held, from dimensional reasoning only: the mean of g = ±1 gives a positive Q_inf of order
0.1 to 1 (plausible range 0.03 to 3), with g = -1 above g = +1. No closed form guessed.
