## 1. Question

Which quadratic graviton charge is the one whose flow JSS's assumption A4 asserts to be modular, for
xi = zeta, the conformal Killing field of the unit ball's diamond in flat space, on odd-parity data; is it
(i) c_l E_2, (ii) c_l E_1, (iii) the literal gauge-dependent expression, (iv) something else.

## 2. JSS's definitions as read (before computing)

- D1, A3/A4 (p. 16): "The flow generated by H^g_xi coincides with the modular flow for some state on the
  algebras A_QFT, A'_QFT"; H^g_xi is "the generator of a specific boost-like flow on A_QFT and A'_QFT".
- D2, (2.3) and text (p. 11): H^g_xi is "the operator generating the flow of xi^a on the quantum field
  algebras ... instantaneously on Sigma_c. It takes the form of a local integral of the matter and graviton
  stress tensors".
- D3, (3.20)-(3.25) (pp. 23-24): with g = g0 + kappa h, the residual constraint current is
  kappa (4 G^(2)_ab - T^(0)_ab) xi^a eps^b; C^(1)[xi] is its integral over the complete slice Sigma_c;
  C^(1)[xi] = (H^g)^(1) + H_obs^(0) + H_ADM^(0); (H^g)^(1) is quadratic in h.
- D4, (3.26)-(3.28) (p. 24): {h, H^g_{kappa xi}} = Lie_xi g0 + kappa Lie_xi h, hence
  {h, (H^g)^(1)} = Lie_xi h, a pure Lie derivative; (H^g)^(0) "generates the linearized diffeomorphism
  delta h = Lie_xi g0".
- D5, (3.11)-(3.13) (pp. 20-21): H^g = H^Sigma - H^Sigma-bar; integral over Sigma of the constraint =
  H^Sigma + H_obs + (kappa_s/2pi) A/4G.
- D6, Section 3.3 (pp. 26-28): gauge condition (H^Sigma)^(-1) = 0, which for a diamond is "proportional to
  the first order change in the volume"; at the next order a proposal only: the surface extremises
  kappa_s A/8piG + V[xi], "V[xi] is a geometric functional whose first order variation agrees with
  (H^Sigma)^(-1)", modelled on A - kV, "we do not treat this problem in detail".
- D7, Section 4.3 (p. 31): "the graviton part of H^g_xi is a known quadratic 'Hamiltonian' for a free
  spin-2 field. We relegate it to future work and do not consider it further."

## 3. Candidate prescriptions (all in charge-id's conventions: d = 4, unit ball, t = 0, N = (1-r^2)/2,
factor 1/8G dropped, Omega(1,2) = int (K1.h2 - K2.h1), odd TT data from `polyalg.py`)

- P1 "canonical, literal (3.28)": C_pure = (1/2) Omega_B(a, delta a), delta = Lie_zeta on the synchronous
  solution H = h + 2tK - t^2 Ric_lin[h] + (t^3/3) Lap K, read back as Cauchy data.
- P1w the same with the background-rescaling term + 2tH (the record's delta^w).
- P2 "stress tensor, literal D3": B = int_B N (K.K - (tr K)^2) - int_B N R^(2)[h]  (= -2 int N G^(2)_tt).
- P3 "one-sided H^Sigma with the area term of D5 and the linear volume functional set to zero on h and
  on the second-order metric separately": B - 2 delta^2 Area[h].
- P4 "fixed true volume" (the record): A_geo = B - 2 delta^2 (Area - 2 Vol)[h].
- P(mu) = B - 2 delta^2 Area[h] + 4 mu delta^2 Vol[h]; mu = 0 is P3, mu = 1 is P4.
- P5 "covariant": the Lie derivative of the linearised Weyl tensor along zeta, on the data (E, B) at t = 0:
  delta E = N dE/dt + 2 sym(x cross B), delta B = N dB/dt - 2 sym(x cross E) (Paper A eq. (1)), with
  E = Ric_lin[h], B = - sym curl K, dE/dt = - sym curl B, dB/dt = sym curl E.

Representatives of one physical datum: TT (profile eta), TT' = TT + c K_l (residual harmonic TT mode),
RW (Regge-Wheeler, h = alpha(r) P).

## 4. Predictions written down before the run (hand derivations, may be wrong; the run decides)

- H1. Every one of P1, P1w, P2, P3, P4 has the same momentum (K-K) block, int_B N K.K, which equals the
  psi-part of c_l E_2 and differs from the psi-part of c_l E_1 by (1/2) c_l int psi^2. No gauge or region
  choice touches it, because K is gauge invariant in the odd sector.
- H2. On the TT representative the field (h-h) blocks are A + lambda int_B |h|^2 with lambda = 1/2 (P1),
  0 (P1w, P4), 1 (P3); P2 = P3 + 2 delta^2 Area[h]. On TT' and RW every one except P4 changes.
- H3. P5 is the weight-1 flow: x.dB.x = N psi_dot and x.curl(dE).x = div(N grad psi) - psi. The flow that
  (3.28) induces on the same curvature data differs from it: Ric_lin[2NK] = dE_P5 + K, and
  - sym curl(delta_pure K) = dB_P5 + sym curl h on TT data; with the + 2tH term the B half agrees with P5.
- H4. The O(s kappa) coefficient of the Riemann tensor of g = (1 - 2st) eta + kappa H + s kappa Lie_zeta H
  (the metric eta + kappa H dragged along zeta) has R_0i0j equal to dE_P5 at t = 0, and vanishing Ricci
  tensor. If true, the diffeomorphism acts on the gauge-invariant curvature by P5, and the difference from
  (3.28) is the bilinear term in (Lie_zeta eta, H) that (3.28) omits.
- H5. Two-sided, R^3 with Gaussian profiles and zeta used globally: (1/2) Omega(a, delta^w a) =
  c_l E_2 on R^3 (same weight, no edge term), B = c_l E_2 + int |h|^2 on TT data.
- H6. Killing control, boost xi = x_1 d_t + t d_1 (lapse x_1): P1 = P2 on R^3, B is invariant under a
  gauge move, and the flow induced by (3.28) on (E, B) equals the Lie derivative of the Weyl tensor.
